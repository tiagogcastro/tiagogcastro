## About

I'm a **Fullstack Developer** with 6+ years of experience building and evolving production software with **Node.js, TypeScript, React, Next.js and AWS**.

I work across the full development lifecycle—from APIs and web interfaces to cloud infrastructure, data pipelines, CI/CD and observability. My recent work combines backend engineering, AWS, DevOps, data platforms and Generative AI.
